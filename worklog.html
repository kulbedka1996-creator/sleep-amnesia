финальная QA-проверка всего сайта на баги
обязательный проход перед сдачейСкролл туда-обратно по всем фазам hero, модалка (открытие/закрытие/ESC/Tab-Trap/возврат фокуса), фильтры и поиск архива, визард-лаборатория (все 7 экранов + назад), звук on/off и старт по жесту, адаптив 320–1440px, клавиатурный проход, консоль на ошибки, Lighthouse. Найденные баги → починено: • растворение по буквам с clip-path давало чёткую вертикальную линию-срез → заменён на эффект расплывающегося текста: blur + opacity + лёгкое scale/translateY, без жёсткой границы. • старт растворения привязан к счётчику жестов колёсика (≥3) → привязала к отметке 1 секунда первого видео. • между блоками Архив и Лаборатория оставалась полоса-разделитель → убрала border-top. • градиент фона Архива не по макету → поправила на #EEEFEC → #E7E4E3. • кегль шагов 01/02/03 был 32px → уменьшен до 20px, отступ между блоками шагов — 60px. • длинная строка стиха «забытые образы выходят из кокона памяти» ломала ритм → перенесла «выходят из кокона памяти» на новую строку.
слабые места → как исправила
починено66 МБ PNG не референсятся в коде → WebP + перенос оригиналов в _source/ + .vercelignore; карточки не открывались с клавиатуры → role=button, tabindex=0, Enter/Space, focus-trap и возврат фокуса в модалке; :focus-visible outline для клавиатурного фокуса.
